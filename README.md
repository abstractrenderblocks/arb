# arb — Abstract Render Blocks

**Deterministic recursive text compiler for structured generation.**

**One source of truth. Many outputs.**

---

## What is arb?

arb (Abstract Render Blocks) is a deterministic recursive text compiler.

It takes structured data and reusable template blocks and renders them into one or more output files — consistently, safely, and without executing arbitrary code.

arb is designed for generating things that must stay in sync:
- documentation
- code scaffolding
- model definitions
- configuration files
- cross-language artifacts

If you’ve ever duplicated the same information across multiple files and watched it drift, arb exists to stop that.
